# Stranded Frontier

Top-down 2D space survival + factory game in **Godot 4.3** (GL Compatibility renderer).
Build a factory by day, survive the horde by night. Semi top-down (3/4) pixel art with Y-sorted depth.

Open the folder in Godot 4.3+ and press **F5**.

## How to play

| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Aim (the astronaut faces where you aim) |
| Space (hold) | Mine the nearest deposit (a beam shows what you're mining) |
| LMB | Shoot (or place the selected building) |
| RMB | Remove a building (50% refund) |
| 1-4 | Select Drill / Conveyor / Gun turret / Tesla coil (or click the hotbar) |
| R | Rotate placement direction |
| Q | Back to shoot mode |
| Tab / I | Open the inventory (click a slot, then another, to move or merge stacks) |

- Everything you mine, and everything your drills deliver to the **core** (your crashed ship), goes into one **inventory** of 12 slots (stacks of 50). When it is full, mining stops and belts back up - there's an "Inventory full!" warning.
- **Drills** go on deposits and push output one tile in their facing direction. The bit stops spinning when the output is blocked.
- **Conveyors** carry items to the core, or into turrets.
- **Gun turrets** are fed ore; **Tesla coils** are fed crystal and hit up to 3 enemies at once. Without ammo they do nothing, so run belts to them.
- Enemies drop **scrap** (needed to build Tesla coils). They attack from the map edge every night and chew through whatever is in their way. Survive 8 nights to win; if the core falls, you lose.
- The hotbar shows how many of each building you can afford (`x3`) and hovering a slot shows its cost.

## Project layout

Everything is a scene made of nodes; scripts only hold behaviour.

```
main.tscn                 Main (orchestrator): DayNight, World, Y-sorted Entities, Projectiles, Effects, Builder, Spawner, HUD
scenes/
  world.tscn              Tiled ground + border (deposits and props live in the Y-sorted Entities layer)
  player.tscn core.tscn builder.tscn
  buildings/              conveyor, drill, turret, tesla  (animated sprites, Area2D range)
  enemies/                enemy (crawler), brute          (Area2D)
  deposits/ props/        ore, crystal / tree, rock
  projectiles/ effects/   bullet, zap / poof (particles), popup (floating text)
  ui/                     hud, hotbar_slot, inv_slot, resource_counter, stat_bar
scripts/                  one script per scene, plus defs.gd (grid/costs), items.gd (item data), inventory.gd (slots/stacks)
assets/sprites/           pixel-art PNGs (generated by tools/make_sprites.py)
assets/ui/theme.tres      HUD theme (panels, bars)
tools/make_sprites.py     redraws all sprites: python3 tools/make_sprites.py
tests/smoke.gd            headless gameplay + inventory smoke test
```

### How the depth works

- The `Entities` node has **Y-sort** enabled, so anything lower on screen draws in front.
- Sprites are drawn with their footprint at the **bottom** of the image (lit top face, darker front face). Each scene anchors that bottom edge to the bottom of its tile, so a tall tower or tree overlaps whatever is behind it.
- Flat things (conveyors) sit on a lower z-index; everything has a soft shadow sprite.

Sprites are simple generated pixel art. To use your own, replace the PNGs in `assets/sprites/` keeping the same names and frame sizes, or edit `tools/make_sprites.py`.
